# 拾影

给摄影师和内容创作者用的 macOS 快速选片工具。把一组照片丢进来，用 `1 / 2 / 3` 快速标记好片、待定和废片，再一键整理成清晰的分类文件夹。

![拾影产品图](assets/marketing/hero.png)

## 为什么用它

- **更快选片**：键盘标记，不用在访达里来回点选。
- **不拆散素材**：同名 RAW、XMP 会跟随对应照片一起整理。
- **本地处理**：照片留在你的 Mac 上，不上传云端。
- **一步归档**：好片、待定、废片按分类整理，减少手动搬文件。

## 功能

- 选择照片文件夹并预览图片
- 支持 JPEG、PNG、HEIC、TIFF 等常见图片
- `1 / 2 / 3` 快速分类
- 全部 / 好片 / 待定 / 废片视图切换
- 同目录同名 RAW/XMP 自动跟随
- 整理到分类文件夹
- 将废片组移动到废纸篓

## 下载

从 GitHub Release 下载 DMG 安装包，打开后把 `拾影.app` 拖到“应用程序”。

> 当前安装包使用本机临时签名，尚未做 Apple 开发者公证。首次打开如果 macOS 提示无法验证开发者，请右键 App 选择“打开”。

## 开发

```bash
swift build
./script/build_and_run.sh
```

生成 DMG：

```bash
./script/package_dmg.sh
```

生成后的安装包位于：

```text
release/拾影.dmg
```

## 系统要求

- macOS 15 或更新版本
- Apple Silicon Mac
